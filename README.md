# Data-Cleaner

A Python script to automatically clean a specific dataset using Pandas. 

## Features
The script processes the data in the following steps:
- **Loading:** Reads the CVS file.
- **Handling Missing Values:** Removes incomplete rows.
- **Removing Duplicates:** Filters out duplicate entries.
- **Type Corrections:** Converts string numbers into proper numeric data types.

> **Note:** The script is used to specific dataset.

## Technologies Used
- Python 3.12
- Pandas

## Usage
   - pip install pandas
